# Runble

**Communication, without the noise.**

Runble is a minimalist desktop communication application developed by **Redproxy**, focused on providing a straightforward experience for messaging, voice communication, and screen sharing.

Designed with simplicity, performance, and usability in mind.

---

## Overview

Runble aims to bring essential communication tools together in a clean, lightweight desktop environment.

The project prioritizes:

- **Messaging** — Simple, direct communication.
- **Voice** — Voice calls without unnecessary complexity.
- **Screen Sharing** — Share your screen or individual application windows.
- **Customization** — Personalize appearance and performance preferences.
- **Efficiency** — An interface designed to minimize distractions and unnecessary resource usage.
